# v0.4.11 — Modül Paleti Yerleşim Yaması

## Sorun

Oyna menüsünden Çevrimiçi Savaş veya Antrenman editörüne geçildiğinde modül
paletindeki `Stack`, üst bileşenden sonlu yükseklik alamıyordu. Kart yalnız
`minHeight` taşıdığı için Flutter web yerleşiminde yükseklik üst sınırı sonsuz
kalıyor ve `Stack size.isFinite` doğrulaması başarısız oluyordu. Ardından boyut
almamış render nesneleri fare izleme sırasında tekrar tekrar hata üretiyordu.

## Çözüm

- Palet kartı yüksekliği 92 px olarak kesinleştirildi.
- İçteki `Stack` artık sonlu 72 px içerik yüksekliği alır.
- Simge, ad, özellikler ve sağ üst sürükleme göstergesi korunur.
- Oyna ekranının açılması Flutter widget ve Python sözleşme testlerine alındı.

Sunucu API'si, veritabanı, kart kuralları ve savaş dengesi değişmemiştir.
