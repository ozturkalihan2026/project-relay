## Yerel Flutter kabul testi

Paketleme ortamında Flutter/Dart SDK bulunmadığından gerçek analiz ve widget
testleri burada çalıştırılamadı. Windows geliştirme bilgisayarında:

```powershell
cd client
.\tool\bootstrap_client.ps1
```

Bu komut `flutter pub get`, `flutter analyze` ve `flutter test` adımlarını
çalıştırır. Ardından oyun:

```powershell
flutter run -d edge --dart-define=RELAY_API_URL=http://127.0.0.1:8000
```
