# Project Relay v0.8.5 rev2 — Widget Test Sürüm Hotfix’i

## Sorun

İstemci ekran başlıkları `v0.8.5` gösterirken ana merkez widget testi Çevrimiçi
Savaş ve Antrenman başlıklarında eski `v0.8.4` metnini bekliyordu. Uygulama
başarılı biçimde açılmasına rağmen test, sürüm metni uyuşmazlığı nedeniyle
duruyordu.

## Düzeltme

- Çevrimiçi Savaş beklentisi `ÇEVRİMİÇİ SAVAŞ • v0.8.5` oldu.
- Antrenman beklentisi `ANTRENMAN • v0.8.5` oldu.
- Kaynak sözleşme testi eski iki beklentinin yeniden eklenmesini engeller.

## Etki

Bu hotfix yalnız test sözleşmesini günceller. Savaş motoru, eşleşme, devre
kayıtları, mağaza, Kariyer, PostgreSQL şeması ve API davranışı değişmez.
