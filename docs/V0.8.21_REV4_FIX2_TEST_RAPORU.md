## Düzeltme

`replay_attack_overlay.dart` içindeki `_AttackPainter` constructor'ı `phaseCue` parametresini alıyordu ancak sınıf alanı önceki fix sırasında yanlışlıkla kaldırılmıştı. `_AttackPainter` içine `final String? phaseCue;` geri eklendi.

Bu düzeltme şu `flutter analyze` hatalarını birlikte kapatır:

- `initializing_formal_for_non_existent_field`
- `undefined_identifier` (`phaseCue`)
- `undefined_getter` (`phaseCue`)

Savaş faz mesajlarının state tarafındaki `_phaseCue` üretimi korunmuştur. Sunucu savaş motoruna dokunulmamıştır.
