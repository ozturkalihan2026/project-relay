# v0.4.1 — UTF-8 Test Düzeltmesi

## Sorun

`session_api_test.dart` içindeki sahte HTTP yanıtları içerik türü
belirtmeden `http.Response` oluşturuyordu. `http` paketi bu durumda metni
Latin-1 ile kodlamaya çalıştığı için `Kalıcı Devre` adındaki noktasız `ı`
karakterinde test, uygulama koduna ulaşmadan hata veriyordu.

## Çözüm

Testteki bütün sahte JSON yanıtları ortak `_jsonResponse` yardımcısıyla
`application/json; charset=utf-8` başlığı taşıyor. Yenilenen erişim
anahtarıyla kart kaydetme isteğinin yalnız bir kez yinelenmesi ve Türkçe kart
adının kayıpsız ayrıştırılması birlikte doğrulanıyor.

Bu değişiklik üretim API'sini, PostgreSQL şemasını, eşleştirmeyi veya savaş
dengesini değiştirmez. Savaş kuralları sürümü `0.7` olarak korunur.
