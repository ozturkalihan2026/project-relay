## Denge regresyonları

Çok uzun yenilmez-strateji matrisi hariç seçili denge paketi:

```bash
RELAY_DATABASE_URL='sqlite+pysqlite:///:memory:' \
python -m pytest -q tests/test_balance.py \
  -k 'not no_server_strategy_is_unbeaten_across_seeded_matchups'
```

Sonuç: **5/5 geçti.**

Bu sürüm savaş motoruna, modül katalog değerlerine veya bot düzenlerine
müdahale etmez.

## Flutter ortam sınırı

Paketleme ortamında Flutter ve Dart SDK komutları bulunmadığı için gerçek
`flutter analyze` ve `flutter test` burada çalıştırılamadı. Kaynaklar yapısal
olarak tarandı ve davranış sözleşmeleri Python testlerinde doğrulandı.

Windows geliştirme bilgisayarında son kabul komutu:

```powershell
cd client
.\tool\bootstrap_client.ps1
```

Kabul ölçütü:

- `flutter pub get` başarılı
- `flutter analyze` sıfır hata
- `flutter test` sıfır hata
