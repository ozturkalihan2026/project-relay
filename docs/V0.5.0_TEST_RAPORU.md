# v0.5.0 Test Raporu

Tarih: 31 Temmuz 2026

## Çalıştırılan doğrulamalar

### Python derleme

```bash
python -m compileall -q relay_api relay_engine tests
```

Sonuç: başarılı.

### Normal sunucu/API/migration/sözleşme testleri

```bash
python -m pytest -q --ignore=tests/test_balance.py
```

Sonuç: **88/88 geçti**.

Kapsam:

- deterministik motor,
- FastAPI bot ve replay uçları,
- JWT misafir/yenileme akışı,
- kalıcı kart ve asenkron eşleştirme,
- ELO benzeri derece ve idempotent maç işlemesi,
- kesin beraberlikte sıfır derece değişimi,
- bot dönüşünde derecesiz sonuç,
- haftalık lig ve maç geçmişi,
- iki katılımcı için perspektif/replay checksum dönüşümü,
- Alembic ileri/geri migration,
- Flutter kaynak sözleşmeleri ve sürüm metinleri.

### Uzun denge matrisi

```bash
python -m pytest -q tests/test_balance.py
```

Sonuç: **6/6 geçti**.

Bu testler modül kombinasyonları, karşı-strateji dengesi ve baskın yerleşim
kontrollerini kapsar. v0.5.0 değişiklikleri savaş motoruna veya kurallar `0.8`
değerlerine dokunmadığından mevcut denge sonuçları korunmuştur.

## Flutter doğrulaması

Bu paket oluşturma ortamında Flutter/Dart SDK bulunmadığı için `flutter analyze`
ve `flutter test` doğrudan çalıştırılamadı. Bunun yerine:

- değiştirilen Dart dosyalarında dize/yorum farkındalıklı ayraç denetimi,
- Python `test_client_contract.py` kaynak sözleşme testleri,
- model ve widget test kaynaklarının v0.5.0 verileriyle güncellenmesi

tamamlandı.

Yerel geliştirme makinesinde son kabul komutları:

```powershell
cd client
flutter pub get
flutter analyze
flutter test
```
