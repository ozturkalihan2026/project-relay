# Project Relay v0.8.20 rev3 — Sohbet Overlay ve Okunmamış Mesaj Hotfix

## Düzeltilen sorun

Global `ChatDock`, `MaterialApp.builder` içinde uygulamanın route Navigator/Overlay ağacıyla kardeş kalıyordu. Bu durum Tooltip, TextField seçim katmanı ve dialog gibi overlay bağımlı widget'larda `No Overlay widget found`, ardından zincirleme `RenderFlex overflow` ve focus/layout hataları üretebiliyordu.

## Çözüm

- MaterialApp builder içine güvenli bir üst `Navigator` eklendi.
- Ekranların mevcut Navigator'ı bu kabuğun içinde korunurken ChatDock üst Navigator'ın Overlay ağacının gerçek alt öğesi oldu.
- Sohbet kapalıyken 5 saniyelik hafif polling ile erişilebilir kanallardaki yeni gelen mesajlar kontrol edilir.
- İlk polling yalnız baseline kurar; geçmiş mesajları okunmamış saymaz.
- Yalnız başka oyuncudan, baseline sonrasındaki mesajlar okunmamış sayılır.
- Kapalı dock toplam okunmamış badge gösterir.
- Açık dock kanal sekmeleri kanal bazlı okunmamış badge gösterir.
- Kanal açılınca o kanalın okunmamış sayacı temizlenir.
