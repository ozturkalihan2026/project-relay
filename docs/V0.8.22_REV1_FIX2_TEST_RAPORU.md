# Project Relay v0.8.22 rev1 fix2 test raporu

Bu düzeltme yalnız Kariyer inline devre editöründeki yükseklik taşmasını giderir. 2.5D hazırlık görseli, savaş sunumu ve savaş motoru değiştirilmez.

## Düzeltme
- Kariyer ekranında oyuncu devresi artık sabit 390 px kareyi zorlamaz.
- Devre alanı `Expanded + LayoutBuilder` ile panelde kalan gerçek yüksekliği ölçer ve en fazla `_careerBoardMaxWidth` boyutunda kare olarak ölçeklenir.
- Aynı esnek yükseklik kuralı rakip devre önizlemesine de uygulanır.
- Böylece test ortamındaki 474 px panel yüksekliğinde görülen 16 px `RenderFlex overflow` giderilir; daha kısa masaüstü pencerelerinde de aynı taşmanın tekrarlaması önlenir.
