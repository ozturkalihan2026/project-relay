# Project Relay v0.8.3 rev2 — Widget Test Kaydırma Hotfix Raporu

**Temel paket:** Project Relay v0.8.3 rev1  
**API:** `0.8.3`  
**Flutter istemci:** `0.8.3+47`  
**Savaş kuralları:** `0.8`

## Yerel kabul bulguları

`flutter analyze` sıfır sorunla tamamlandı. `flutter test` sırasında iki test,
800×600 test yüzeyindeki görünürlük koşulları nedeniyle başarısız oldu:

1. Profilin yatay bölüm seçicisindeki **Günlük Görevler** seçeneği ekranın sağında
   kaldığı için doğrudan `tap()` hedefe ulaşmadı.
2. Koleksiyonun Kozmetik bölümündeki **Ana Menüye Dön** düğmesi, dikey
   `ListView` henüz alt bölümü oluşturmadığından `ensureVisible()` başlangıçta
   finder bulamadı.

## Uygulanan çözüm

- Profil bölümleri için `_tapProfileSection` test yardımcısı eklendi. Yardımcı,
  `AxisDirection.right` yatay `Scrollable` üzerinde hedef sekmeyi
  `scrollUntilVisible` ile görünür yapıp ardından tıklar.
- Koleksiyon geri düğmesi, `collection-scroll-view` içindeki aşağı yönlü
  `Scrollable` üzerinde `scrollUntilVisible` kullanılarak oluşturulur ve
  tıklanır.
- `warnIfMissed: false` kullanılmadı; başarısız tıklamalar gizlenmedi.

## Değişmeyen alanlar

- Uygulama ekranlarının ürün davranışı
- FastAPI ve HTTP sözleşmesi
- PostgreSQL/Alembic şeması
- Savaş motoru ve modül dengesi
- Komutan Sistemi ve Oyuncu Tarzı Profili özellik havuzu kararı
