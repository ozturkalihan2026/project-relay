## Ortam nedeniyle çalıştırılamayan kontroller

### Flutter araçları

Çalışma ortamında Flutter/Dart SDK bulunmadığı için aşağıdaki komutlar çalıştırılamadı:

- `flutter analyze`
- `flutter test`

Bunun yerine istemci sözleşme testleri ve 41 Dart dosyasını kapsayan ayraç/sözdizimi ön taraması çalıştırıldı.

### Tam Python test paketi

Tam `unittest` keşfi 80 testi yüklemeyi denedi; veritabanı bağlantılı 9 test modülü, çalışma ortamında `psycopg` paketi bulunmadığı için import/aşama hatasıyla başlayamadı. Bunlar uygulama iddiası veya test assertion başarısızlığı değildir. Paket içindeki bağımlılık tanımı değiştirilmedi.

## Yerel doğrulama önerisi

Flutter kurulu geliştirme bilgisayarında paket açıldıktan sonra:

```powershell
cd client
flutter pub get
flutter analyze
flutter test
```

Sunucu bağımlılıkları kurulduktan sonra proje kökünde:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests
```
