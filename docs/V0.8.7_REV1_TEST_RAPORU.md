# Project Relay v0.8.7 rev1 Test Raporu

## Kapsam

Bu hotfix, Flutter analyzer tarafından bildirilen üç bulguyu kapatır:

- Profil ekranındaki kullanılmayan `_MetricBox.accent` parametresi.
- Haftalık lig satırında modelde bulunmayan `LeagueStanding.matches` erişimi.
- İstatistikler ekranındaki kullanılmayan `_MetricBox.accent` parametresi.

## Uygulanan düzeltmeler

- Haftalık lig toplam maç değeri `wins + draws + losses` olarak hesaplanır.
- Profil ve İstatistikler ekranındaki `_MetricBox` bileşenleri sabit cyan vurguyla
  sadeleştirildi; kullanılmayan `accent` parametreleri kaldırıldı.
- İstemci yapı numarası `0.8.7+56` olarak güncellendi.
- Kaynak sözleşme testleri v0.8.7 menü ve profil mimarisine göre güncellendi.

## Doğrulama

- Normal Python regresyonları: **140/140 geçti**.
- Denge testleri: **6/6 geçti**.
- İstemci kaynak sözleşmeleri: **36/36 geçti**.
- `standing.matches`, `_MetricBox.accent` ve `this.accent` kalıpları ilgili
  ekranlardan kaldırıldı.

## Ortam sınırlaması

Bu çalışma ortamında Flutter/Dart SDK bulunmadığı için gerçek `flutter analyze`
ve `flutter test` çalıştırılamadı. Son Flutter kabulü yerel geliştirme ortamında
`client/tool/bootstrap_client.ps1` ile yapılmalıdır.
