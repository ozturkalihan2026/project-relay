# Project Relay v0.8.3 rev1 — Flutter Analiz Hotfix Raporu

**Temel paket:** Project Relay v0.8.3  
**Flutter istemci:** `0.8.3+46`  
**API:** `0.8.3`  
**Savaş kuralları:** `0.8`  
**Alembic başı:** `20260801_0009`

## Yerel analizde bildirilen sorunlar

Kullanıcının Windows geliştirme ortamında `flutter analyze` toplam yedi bulgu
raporladı:

- `profile_screen.dart`: iki `invalid_null_aware_operator` uyarısı,
- `player_status_bar.dart`: iki `invalid_null_aware_operator` uyarısı,
- `social_screen.dart`: bir `invocation_of_non_function_expression` hatası,
  bir `duplicate_definition` hatası ve buna bağlı bir `unused_element` uyarısı.

## Uygulanan düzeltmeler

- `progression.asData?.value?.…` erişimleri, `AsyncData.value` alanı null
  olmadığı için `progression.asData?.value.…` olarak düzeltildi.
- `_ClanSection _clanSection` durum alanı `_selectedClanSection` olarak
  yeniden adlandırıldı. `_clanSection(...)` widget oluşturma metodu değişmeden
  kaldı. Böylece metot çağrısı yeniden çağrılabilir hâle geldi ve yinelenen ad
  kaldırıldı.
- Kaynak sözleşmesine bu kalıpların tekrar eklenmesini engelleyen regresyon
  kontrolleri eklendi.

## Paketleme ortamında doğrulama

- `python -m compileall -q relay_api relay_engine tests`: başarılı
- Uzun denge matrisi hariç normal Python paketi: **140/140 geçti**
- Seçili denge regresyonları: **5/5 geçti**
- Analyzer bulgularına neden olan kaynak kalıpları: kaldırıldı
- API, Alembic, savaş motoru ve modül dengesi: değişmedi

Bu çalışma ortamında Flutter/Dart SDK bulunmadığı için gerçek `flutter analyze`
ve `flutter test` burada çalıştırılamadı. Son yerel kabul komutu:

```powershell
cd client
.\tool\bootstrap_client.ps1
```

Kabul ölçütü: `flutter analyze` ve `flutter test` sıfır hata.
