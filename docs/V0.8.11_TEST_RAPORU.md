# Project Relay v0.8.11 Test Raporu

## Kapsam

Bu paket v0.8.10 üzerine uygulanan istemci ağırlıklı arcade-tech görsel
yenilemedir. Oyun mantığı, API davranışı, veritabanı şeması ve denge değerleri
değiştirilmemiştir.

## Uygulanan kontroller

- İstemci kaynak sözleşmeleri: 40/40 geçti.
- PostgreSQL sürücüsü gerektirmeyen normal Python testleri: 113/113 geçti.
- Denge testleri: 6/6 ayrı ayrı geçti.
- Dart kaynak delimiter/string/comment yapısal taraması geçti.
- YAML doğrulaması geçti.
- Python derleme kontrolü geçti.
- ZIP bütünlük ve temizlik kontrolü paketleme sırasında uygulandı.

## Ortam sınırlamaları

Paketleme ortamında Flutter SDK bulunmadığı için `flutter analyze` ve
`flutter test` burada çalıştırılamadı. PostgreSQL `psycopg` sürücüsü bulunmadığı
için `test_api.py`, `test_online.py` ve `test_social_api.py` bu ortamda
toplanamadı. Yerel kabul `client/tool/bootstrap_client.ps1` ile tamamlanmalıdır.
