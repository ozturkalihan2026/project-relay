# Project Relay v0.8.22 rev1 fix1 test raporu

Bu revizyon yalnız hazırlık sahnesini düzeltir. Savaş motoru ve savaş sunumu değiştirilmez.

## Görsel düzeltmeler
- Hazırlık kartının perspektif yönü tersine çevrildi: ön/alt kenar oyuncuya yaklaşır (`deckTilt = -0.32`).
- Perspektif kuvveti `perspectiveDepth = 0.00155` olarak ayarlandı; platform katmanları ve ön kalınlık daha görünür yapıldı.
- Modül gövdeleri kare hücre çerçevesinden ayrıldı; kesik köşeli, yüzeyden yükselmiş `ModuleChassis` kullanıyor.
- Yeni yerleşen modül 240 ms'lik fiziksel oturma animasyonuyla yuvaya yaklaşır.
- Paletten sürüklenen modül artık 3D donanım önizlemesiyle taşınır.
- Başarılı yerleştirme/taşıma işleminde `module_lock.wav` metalik bağlantı sesi çalınır.

## Kabul ölçütü
- Kart, aşağı doğru bakan pano değil oyuncuya doğru yükselen elektronik platform gibi algılanmalı.
- Dolu hücre, boş slotun içine çizilmiş kare değil slotun üstüne takılmış fiziksel modül gibi görünmeli.
- Modül bırakma anında kısa ve tok bağlantı sesi duyulmalı.

## Otomatik kontroller
Teslim öncesinde Python derleme, engine/denge, istemci kaynak sözleşmeleri ve ZIP bütünlüğü kontrol edilir. Flutter SDK bu çalışma ortamında bulunmadığından `flutter analyze` ve `flutter test` yerel Windows kabulünde çalıştırılmalıdır.
