# Project Relay v0.8.4 rev2 — Widget Test Hotfix

**API:** `0.8.4`  
**Flutter istemci:** `0.8.4+50`  
**Savaş kuralları:** `0.8`

## Sorunlar

Yerel Flutter kabulünde iki test sorunu görüldü:

1. Profil ekranının altındaki **Ana Menüye Dön** düğmesi 800×600 test alanının
   dışında kaldığı hâlde kaydırma animasyonu tamamlanmadan tıklanıyordu.
2. Profil bölüm yardımcısı ekrandaki bütün sağ yönlü `Scrollable` bileşenlerini
   buluyordu. Genel profil içindeki düzenlenebilir metin alanı ikinci bir yatay
   kaydırıcı oluşturduğu için test tek sonuç beklentisinde duruyordu.

## Düzeltme

- Profil geri düğmesi için `findsOneWidget`, `ensureVisible`, ardından
  `pumpAndSettle` uygulanır.
- Ana menüde Ayarlar düğmesinin geri dönüşten sonra gerçekten oluştuğu
  doğrulanır.
- Profil sekmesi yardımcısı yalnız seçilen sekmenin sağ yönlü `Scrollable`
  atasını hedefler.
- `warnIfMissed: false` kullanılmaz; test hataları gizlenmez.
