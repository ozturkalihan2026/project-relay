## Otomatik testler

Aşağıdaki komut SQLite test veritabanıyla çalıştırıldı:

```bash
RELAY_DATABASE_URL='sqlite+pysqlite:///:memory:' \
python -m pytest -q --ignore=tests/test_balance.py
```

Sonuç: **124/124 test geçti.** Dağılım:

- API: 20
- Kimlik doğrulama: 3
- Kariyer: 8
- Flutter kaynak sözleşmeleri: 32
- Koleksiyon ve kit: 6
- Rekabet: 6
- Savaş motoru: 27
- Alembic geçişleri: 2
- Çevrimiçi akış: 11
- İlerleme ve ekonomi: 9

Denge paketindeki uzun matris dışındaki beş gerileme testi ayrıca geçti:

```bash
python -m pytest -q tests/test_balance.py \
  -k 'not no_server_strategy_is_unbeaten_across_seeded_matchups'
```

Toplam doğrulanan Python testi: **129**.
